Event log (cereal-style)

What is real here? Lane detection is genuine computer vision on rendered pixels (thresholding → runs → RANSAC-style quadratic fit). The driving policy is a real neural net trained by behaviour cloning of the planner (with DAgger-style aggregation while it drives). The cut-in predictor is an online-trained logistic regression. Future sampling is a hand-parameterised mixture model driven by that classifier. Object detection is simulated (ground truth + range-dependent noise/dropout, monocular range geometry) - swap in a real detector like YOLO to go further. This mirrors openpilot's architecture but does not run openpilot's code (which needs Linux + comma hardware/MetaDrive).
